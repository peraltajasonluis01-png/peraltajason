# Jason Luis Peralta - GitHub Page & Portfolio

Modern, sleek, and minimalist personal developer website and project showcase designed for **GitHub Pages**.

🔗 **Live URL:** [https://peraltajasonluis01-png.github.io/peraltajason/](https://peraltajasonluis01-png.github.io/peraltajason/)

---

## 🎨 Theme & Design Philosophy

- **Background:** Deep midnight & navy blue (`#040814` to `#070d1e`) with soft ambient cyan & royal blue blurs.
- **Text & Contrast:** High-contrast bright whites (`#ffffff`, `#f8fafc`) and luminous sky blues (`#bae6fd`), paired with electric cyan highlights (`#38bdf8`, `#00f2fe`).
- **Cards & Structure:** Glassmorphic translucent cards (`backdrop-filter: blur(...)`) with delicate borders that glow on hover.
- **Tech Stack:** Vanilla **HTML5**, modern **CSS3** (CSS custom properties, Flexbox, Grid), and lightweight **JavaScript** (zero build step, instant deployment on GitHub Pages).

To publish these changes to your live GitHub Pages site:

```bash

```

`https://peraltajasonluis01-png.github.io/peraltajason/`
